## ✨ Why Nexora?

Your online identity is usually scattered across GitHub, LinkedIn, portfolios, resumes, and social platforms.

**Nexora brings that identity together.**

It is designed as a developer-first profile experience: clean enough for recruiters, expressive enough for creators, and structured enough to grow into a full identity platform.

## 🚀 Highlights

- **Developer-first profile** — Present your identity, bio, skills, and work in one place.
- **Project showcase** — Highlight the work that matters instead of dumping every repository onto one page.
- **Social hub** — Connect GitHub, LinkedIn, portfolio, and other professional destinations.
- **Responsive by design** — Built to feel intentional across mobile, tablet, and desktop.
- **Modern interactions** — Subtle motion and micro-interactions keep the experience engaging without getting in the way.
- **Accessible UI** — Semantic structure, keyboard-friendly interactions, and clear visual hierarchy.
- **Fast frontend** — Vite-based development and a lightweight component stack.

## ⚡ Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/harshitdev-wq/nexora-developer-profile.git
cd nexora-developer-profile
npm install
```

### Start development server

```bash
npm run dev
```

Vite will provide a local development URL in your terminal.

### Production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## 🎯 Product Direction

Nexora currently focuses on the **public developer identity experience**. Future iterations can evolve it into a more complete platform with features such as:

- GitHub profile integration
- Dynamic project importing
- Custom profile URLs
- Shareable profile cards
- Analytics for profile visits and link clicks
- Custom themes
- Profile editing dashboard
- Open Graph / social preview generation

## 🧠 What I Learned

Building Nexora was an exercise in turning a simple idea — **"one link for a developer's identity"** — into a responsive product interface.

The project focuses on component-driven UI, responsive layout decisions, reusable styling, interaction design, and deployment rather than simply creating a static landing page.
