# Contributing to Nexora

Thanks for your interest in improving Nexora.

## Before you start

- Read the README and understand the project structure.
- Keep changes focused and easy to review.
- Test responsive behavior before opening a pull request.
- Do not commit secrets, API keys, `.env` files, or generated build output.

## Development

```bash
npm install
npm run dev
```

Before submitting a PR, make sure the production build succeeds:

```bash
npm run build
```

## Pull requests

Please explain what changed, why it changed, and how you tested it. For UI changes, include screenshots when useful.
